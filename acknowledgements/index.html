Acknowledgements & inspirations

This site is built on other people's good ideas and good code. Where something was borrowed, adapted, or learned from, it's named here — and, where it matters, in the piece that uses it.

gwern.net — Gwern Branwen (& Said Achmiz)

The largest influence by far. The reading experience here is an homage to gwern.net's:

  • Sidenotes. The margin-note behaviour follows gwern's sidenotes.js (by Said Achmiz, MIT). gwern's file is coupled to its larger site engine, so this site reuses the pattern — a small self-contained reimplementation — rather than the file itself. Demonstrated in “Sidenotes, previews, and other quiet machinery”.
  • Link / document previews. The hover-preview cards are inspired by gwern's popups (popups.js / extracts.js): annotations compiled at build time, shown on hover. This implementation is custom.
  • The whole philosophy — static HTML rendered at build time, aggressive progressive enhancement (the site is fully readable with JavaScript off), speed, and a “semantic zoom” approach to links.
  • gwtar — gwern's single-file self-extracting HTML archive format, on the roadmap here for link archiving.

Sidenotes lineage

  • Tufte-CSS / Edward Tufte — sidenotes as a form originate here; gwern's version (and therefore this one) build on it.
